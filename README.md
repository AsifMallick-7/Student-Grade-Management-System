## 📖 About the Project

This **Student Grade Management System** is a simple and efficient program written in **C language**.  
It allows users to manage student data — including **adding, updating, deleting, sorting, and grading** records.  

💡 Perfect for beginners learning:
- Arrays  
- Strings  
- Functions  
- Loops  
- Conditionals  
- Data manipulation  

---

## ✨ Features

✅ Add new student records  
✅ Display all students  
✅ Search students by roll number  
✅ Automatically calculate total, percentage & grade  
✅ Sort students by total marks (descending order)  
✅ Update or delete existing records  
✅ Handles up to **100 students** and **3 subjects**

2. Copy the code into a file named `student_grade_system.c`
3. Open terminal / command prompt in that folder.
4. Compile and run:
   ```bash
